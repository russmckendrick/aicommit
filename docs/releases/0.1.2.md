# aicommit 0.1.2

A maintenance release: a signed, self-contained Windows binary, no terminal UI on CI runners, and refreshed dependencies.

## Changed

- Plain `aic` no longer opens the terminal UI on a CI runner, even when the runner attaches a terminal. Azure Pipelines (`TF_BUILD`), GitHub Actions (`GITHUB_ACTIONS`), and anything else that sets `CI` are detected; `aic --tui` still opens it. See [Terminal UI](../tui.md).
- The Windows binary (`aic-windows-amd64.exe`) is now code-signed, so Windows can verify who published it.
- The Windows binary now links the C runtime statically, so `aic.exe` no longer needs the Visual C++ Redistributable (`vcruntime140.dll`) to be installed.
- Updated transitive dependencies to their latest compatible versions.
